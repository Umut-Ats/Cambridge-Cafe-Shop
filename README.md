# Cambridge-Cafe-Shop

A simple static page listing independent coffee shops in Cambridge, UK.

🌐 **Live site:** https://umut-ats.github.io/Cambridge-Cafe-Shop/

Deployed automatically to GitHub Pages via GitHub Actions on every push to the main branch.

An [`llms.txt`](llms.txt) file is included at the site root to give AI assistants and crawlers a machine-readable index of the coffee shops listed on the page.
